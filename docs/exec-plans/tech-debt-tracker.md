# 기술 부채 추적기

> QualityScorer와 DocGardener 에이전트가 주기적으로 업데이트합니다.

## 현재 기술 부채

| ID | 영역 | 설명 | 심각도 | 상태 |
|----|------|------|--------|------|
| (초기 구축 중) | - | - | - | - |

## 심각도 기준

- **critical**: 즉시 해결 필요 — 기능 장애 또는 보안 위험
- **high**: 이번 주 내 해결 — 아키텍처 위반, 성능 저하
- **medium**: 이번 달 내 해결 — 코드 중복, 문서 부재
- **low**: 시간 될 때 해결 — 스타일 불일치, 마이너 개선

## 해결 프로세스

1. QualityScorer가 편차 감지 → 이 파일에 기록
2. 심각도에 따라 실행 계획 생성 또는 즉시 수정
3. CodeAgent가 수정 PR 생성
4. 해결 시 상태를 `resolved`로 변경
