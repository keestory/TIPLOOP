## 사양 작성 가이드

PM 에이전트가 제품 사양을 작성할 때 이 디렉토리에 저장합니다.

### 필수 항목
1. **요약**: 한 줄 설명
2. **사용자 스토리**: As a [역할], I want [기능], so that [가치]
3. **수용 기준**: Given-When-Then 형식 (QA 에이전트가 검증)
4. **화면/플로우**: 단계별 사용자 흐름 (Designer 에이전트가 참조)
5. **엣지 케이스**: 예외 상황과 기대 동작
6. **비기능 요구사항**: 성능, 접근성, 보안, 국제화
7. **우선순위**: 영향도 × 노력 매트릭스
8. **Out of Scope**: 이번에 하지 않는 것

### 상태 정의
- **draft**: PM이 작성 중
- **review**: 이해관계자 리뷰 중
- **approved**: 승인, 구현 가능
- **in-progress**: 구현 중
- **done**: 구현 완료, QA 통과
- **archived**: 더 이상 유효하지 않음

### 핸드오프 체크리스트

PM → Planner/Coder 핸드오프 전:
- [ ] 수용 기준이 구체적이고 검증 가능한가?
- [ ] 엣지 케이스가 식별되었는가?
- [ ] 비기능 요구사항이 명시되었는가?
- [ ] Out of Scope이 명확한가?
- [ ] 디자인 요구사항이 있다면 Designer에게 전달했는가?
