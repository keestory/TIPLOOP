# 제품 사양 — TIPLOOP 개인 서비스 연구 노트

> 상태: implemented — 질문 선택·비공개 미디어 검증 중
> 최종 업데이트: 2026-09-03

## 요약

TIPLOOP은 다른 서비스의 기능·기획·UX·콘텐츠·마케팅·비즈니스 모델·운영 모델을 구조적으로 기록하고, 내 서비스에 적용할 아이디어까지 축적하는 개인 연구 노트다.

핵심 루프는 `서비스 발견 → 빠른 저장 → 구조화 분석 → 검색·재열람 → 적용 아이디어 실행`이다.

## 사용자 스토리

- 나는 서비스 기획·운영 실무자로서 서비스 링크와 관찰 이유를 빠르게 저장하고 싶다. 그래야 나중에 분석할 대상을 놓치지 않는다.
- 나는 하나의 서비스 분석을 정해진 관점으로 기록하고 싶다. 그래야 분석의 깊이와 형식을 반복할 수 있다.
- 나는 과거 분석을 서비스명·기능·인사이트로 검색하고 싶다. 그래야 새 기획을 할 때 근거로 다시 꺼낼 수 있다.
- 나는 기록을 수정하며 적용 결과를 보완하고 싶다. 그래야 일회성 메모가 아니라 누적되는 연구 자산이 된다.

## 화면과 흐름

1. 로그인 후 홈에서 내 최근 서비스 연구 노트와 분석 진행도를 본다.
2. 링크를 붙여 새 분석 폼으로 이동하거나 `분석` 버튼을 누른다.
3. `5분 빠른 분석`, `질문 골라 분석`, `전체 분석` 중 깊이를 고른다.
4. 서비스명·링크와 선택한 관점을 작성하고, 필요하면 이미지나 짧은 영상을 첨부한다.
5. 저장 후 비공개 상세 화면에서 전체 기록과 첨부를 읽는다.
6. 보관함에서 제목과 본문을 검색하고, 필요한 기록을 다시 열어 수정한다.
7. `실제로 적용할 것`을 쓴 기록은 홈 지표에서 적용 큐로 다시 연다.

## 수용 기준

- Given 비로그인 사용자, When 홈·보관함·분석 상세에 접근하면, Then 로그인 화면으로 이동한다.
- Given 로그인 사용자 A, When 사용자 B의 기록 URL에 접근하면, Then 기록 내용을 볼 수 없다.
- Given 로그인 사용자, When 홈을 열면, Then 본인이 작성한 서비스 분석만 최신순으로 본다.
- Given 서비스 분석 폼, When 서비스명과 하나 이상의 분석 항목을 작성하면, Then 연구 노트가 저장되고 상세 화면으로 이동한다.
- Given 서비스 분석 폼, When 작성 중 브라우저가 닫혔다가 돌아오면, Then 같은 기기의 임시 초안을 복원한다.
- Given 서비스 분석 폼, When 빠른·직접 선택·전체 모드를 바꾸면, Then 해당 질문만 표시하고 이미 쓴 답은 보존한다.
- Given 이미지나 영상을 선택, When 형식·개수·크기 제한을 통과하면, Then 현재 계정의 비공개 Storage 경로로 업로드하고 노트에 경로 메타데이터만 저장한다.
- Given 저장된 비공개 첨부, When 작성자가 상세를 열면, Then 짧게 만료되는 signed URL로만 표시한다.
- Given 다른 로그인 사용자, When 첨부 경로를 추측하거나 요청하면, Then Storage RLS가 읽기와 삭제를 거부한다.
- Given 저장된 연구 노트, When 수정 후 저장하면, Then 동일한 기록이 갱신된다.
- Given 검색어, When 보관함 검색을 실행하면, Then 본인 기록의 제목 또는 본문과 일치하는 결과만 나온다.
- Given 서비스 분석 화면, Then 공개 URL 기반 업로드와 커뮤니티 반응·초대 기능은 노출하지 않는다.
- Given 예전 자유 형식 본문이나 첨부 URL, When 연구 노트를 열고 수정하면, Then 이전 메모와 첨부 참조를 숨기거나 삭제하지 않는다.

## 비기능 요구사항

- 개인 연구 노트는 기본적으로 작성자 본인만 조회·수정한다.
- 폼은 실제 label 연결, 인라인 오류, 첫 오류 포커스, 중복 제출 방지를 제공한다.
- 폼은 400ms 지연 로컬 초안 저장·복구와 textarea 자동 높이 조절을 제공한다. 브라우저 보안상 선택한 로컬 파일 자체는 새로 선택해야 한다.
- 첨부는 합계 6개, 영상 1개, 전체 100MiB까지 허용한다. 이미지는 파일당 10MiB, 영상은 파일당 50MiB까지다.
- 비공개 첨부는 `<auth_uuid>/drafts/<draft_uuid>/<object_uuid>.<ext>` 경로를 사용하고 DB에는 public·signed URL을 저장하지 않는다.
- 모바일 390px 폭에서 가로 스크롤 없이 작성·검색·조회할 수 있다.
- 기존 Field Notes 디자인 토큰을 유지하고 WCAG 2.2 AA를 목표로 한다.
- 진행 막대는 progressbar 의미와 현재 값을 제공하고, 작은 메타 텍스트와 주요 터치 대상은 AA 대비·44px을 목표로 한다.
- public 앱 테이블 13개는 RLS를 사용하며 browser 역할 정책이 있거나 검증에 실패하면 앱 시작을 중단한다.
- DB를 사용하는 환경은 32자 이상의 세션 비밀키를 강제하고 세션 쿠키를 기본 HTTPS 전용으로 발급한다.

## 2026-09-01 시장 스냅샷

- 한국 iPhone [비즈니스 무료 차트](https://apps.apple.com/kr/iphone/charts/6000?chart=top-free) 상위권은 채용·고용, 협업, 업무 인증, 현장 운영처럼 즉시 해결되는 업무 도구가 중심이다. 상위 25개에서 TIPLOOP과 같은 개인 서비스 연구 노트는 확인되지 않았다.
- [비즈니스 유료 차트](https://apps.apple.com/kr/iphone/charts/6000?chart=top-paid)는 POS, 원격 데스크톱, 녹음, 스캔처럼 반복 효용이 분명한 단일 목적 도구가 강하다.
- 인접 제품인 [Notion](https://apps.apple.com/kr/app/notion-%EB%A9%94%EB%AA%A8-%EC%9E%91%EC%97%85-ai/id1232780281)은 생산성 차트에서 강한 범용 대안이므로, TIPLOOP은 메모 기능보다 `분석 관점의 반복성`과 `실제 적용`에서 차별화해야 한다.

이 스냅샷은 시장성이 없다는 증거가 아니라, 넓은 메모 앱으로는 경쟁하기 어렵다는 신호다. 먼저 PWA에서 개인 사용의 `캡처→분석 완료→재열람→적용`을 검증하고, 앱스토어 출시는 반복 사용이 확인된 뒤 판단한다.
