# 제품 사양 — 티핑(Tipping): 커머스·IT 실무자 커뮤니티

> 상태: MVP 사양 (이음 → 티핑 피벗 후 재정의)

## 한 줄 정의

커머스·IT 실무자가 일하며 얻은 **팁**과 다른 서비스를 뜯어본 **레퍼런스**를 기록하고,
혼자만의 메모를 넘어 **커뮤니티로 나누는** 곳.

## 왜 만드는가 (문제)

1. **좋은 실무 지식이 흩어진다** — 노하우·레퍼런스가 개인 노션·북마크에 갇혀 축적도 검색도 안 된다.
2. **레퍼런스 공부가 사라진다** — 다른 서비스를 뜯어보며 배운 걸 정리해도 나만 보고 끝난다.
3. **회고·질문이 닫혀 있다** — 실무 고민을 나눌 열린 동료 공간이 마땅치 않다.

## 누구를 위한 것인가

- **주 사용자**: 커머스·IT 실무자 — PM·개발·디자인·마케팅·데이터·기획·MD·운영
- **맥락**: 업무 틈새/퇴근 후. 빠르게 훑고, 좋은 글은 공감·저장, 레퍼런스는 링크 따라가기.

## 무엇을 하는가 (카테고리 = 글의 종류)

| 카테고리 | 쓰는 것 |
|----------|---------|
| **팁** | 실무 노하우·꿀팁 |
| **레퍼런스** | 다른 서비스/아티클 뜯어보기 (참고 **링크** 첨부) |
| **질문** | 동료에게 묻기 |
| **회고** | 프로젝트 회고·인사이트 |

## 수용 기준 (Acceptance Criteria)

- [ ] **구글·카카오 소셜 로그인**으로 가입한다(이메일/비밀번호 없음).
- [ ] 소셜이 주지 않는 **직군·연차·업종**을 온보딩에서 받는다.
- [ ] 로그인 회원은 네 카테고리 중 하나로 글을 쓴다. **레퍼런스**는 참고 링크를 붙일 수 있다.
- [ ] 누구나(비로그인 포함) 피드와 글을 **읽을 수 있다** (오픈 원칙).
- [ ] 피드는 **정렬(최신·공감·화제)** + **필터(카테고리·직군·업종)**로 탐색된다.
- [ ] 로그인 회원은 글/댓글에 **공감(♥)**, **댓글·답글**을 남긴다.
- [ ] 각 회원 **프로필**에서 그가 쓴 글과 **받은 공감(카르마)**을 본다.

## 명시적으로 MVP에서 빼는 것

- 저장(북마크)·팔로우·알림·검색엔진·태그 — 다음 단계.
- 먼저 **기록 → 피드 → 반응**의 기본 루프가 좋아야 한다.

## 성공의 모습 (정성)

- 한 사람의 **레퍼런스 뜯어보기**가 다른 실무자의 실제 개선으로 이어진다(댓글로 결과 공유).
- 흩어졌을 팁이 **검색 가능한 커뮤니티 자산**으로 쌓인다.
