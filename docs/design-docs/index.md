## 설계 문서 작성 가이드

1. [템플릿](../../templates/design_doc_template.md)을 복사하여 시작
2. 상태를 `draft`로 설정
3. 리뷰 완료 후 `confirmed`로 변경
4. 인덱스에 추가

## 상태 정의

- **draft**: 초안, 피드백 수집 중
- **confirmed**: 확정, 구현 가능
- **superseded**: 새로운 문서로 대체됨
- **archived**: 더 이상 유효하지 않음
