# 설계 문서 — 이음(Ieum)

## 제품 성격에서 출발

교사들의 공간. **교육적·신뢰감·차분함.** SaaS 대시보드도, 아동용 앱도 아니다.
읽고 쓰는 글이 중심 → *에디토리얼(잡지/지면)에 가까운* 정돈된 느낌.

의도적으로 피한 것 (DESIGN_SYSTEM.md 안티패턴):
- 파랑 Primary + 빨강 Danger + 초록 Success 신호등 팔레트 ✗
- 둥근 모서리 + 연한 그림자 카드 ✗ → **헤어라인 구분선 + 여백**으로 위계
- 좌측 사이드바 고정 레이아웃 ✗ → **중앙 1단 읽기 칼럼**
- sm/md/lg 전체 변형 ✗ → 실제 쓰는 크기만

## 디자인 시스템 (정의된 것만)

### 컬러 — 3색 + 보조
| 토큰 | 값 | 왜 |
|------|-----|-----|
| `--ink` | `#20211c` | 본문. 순흑 대신 따뜻한 먹빛(분필/지면 느낌) |
| `--paper` | `#faf8f3` | 배경. 흰색 대신 미색 종이 |
| `--brand` | `#a8432a` | 링크·액션. 파랑을 거부한 황톳빛 테라코타 = 따뜻함·한국적 정서 |
| `--muted` | `#6b6a63` | 보조 텍스트·메타 |
| `--line` | `#e4ddcf` | 헤어라인 구분선(그림자 대신) |
| `--warn` | `#9a6b16` | 경고 한 가지만 (위험/성공 분리 안 함) |

"왜 이 값인가"에 답할 수 있음: 파랑을 의도적으로 버리고, 종이·먹·황토라는 **교실/지면 정서**로 정체성을 만든다.

### 타이포그래피
- 제목: 세리프(`Noto Serif KR`, serif) — 지면 느낌, SaaS와 차별.
- 본문: 산세리프(시스템/`Pretendard`) 17px, line-height 1.7 (긴 글 가독성).
- 크기 단계: 본문 17 / 소제목 21 / 제목 28 — 3단계면 충분.

### 스페이싱
- 기본 단위 **8px**. 화면에서 편한 간격을 8의 배수로(8·16·24·40).

### 컴포넌트 (실제 쓰이는 것만 5종)
1. **헤더** — 로고(이음) + 글쓰기/로그인. 상단 고정 안 함, 그냥 흐름 위.
2. **필터 바** — 카테고리·학교급·지역 칩.
3. **글 항목(피드 행)** — 카드 아님. 제목 + 메타(작성자·학교급·지역·카테고리) + 구분선.
4. **글 본문** — 읽기 칼럼(max 720px).
5. **폼** — 입력/선택/버튼. 버튼은 단 1종(brand) + 보조 텍스트 링크.

### 카테고리 표식
색 점이나 신호등 대신 **짧은 한글 라벨 태그**(테두리 칩): `정보공유` `세미나` `고민나눔`.

## 인게이지먼트 레이어 (Reddit 참고, 교사 톤으로 변형)

"쓰고 싶게 · 읽고 싶게 · 반응하고 싶게" 만드는 상호작용을 이식하되, 팔레트·레이아웃은
이음의 종이·먹·황토를 유지한다(클리셰 회피).

| Reddit 메커니즘 | 이음 적용 | 왜 변형했나 |
|-----------------|-----------|-------------|
| 업/다운보트 점수 | **공감(♥)** 단일 반응 | 다운보트는 고민·공유를 위축. 지지 커뮤니티엔 부적합 |
| Hot/New/Top 정렬 | **최신 · 공감 · 화제(댓글)** 탭 | 다시 올 이유를 만든다 |
| 댓글 수 어포던스 | 피드에 `♥ 공감 N` · `💬 댓글 N` 노출 | 반응 진입점을 눈앞에 |
| 중첩 댓글 | **답글 1단계** (들여쓰기 + 좌측 선) | 무한 중첩은 교사 대화엔 과함 |
| Karma | 프로필 **받은 공감 합계** | 인정 욕구 → 쓰고 싶게 |
| Create Post 입력칸 | 피드 상단 **작성 유도 박스** | 빈 입력칸이 글쓰기 문턱을 낮춘다 |

공감 버튼 상태: 비활성(테두리 ♥ 먹빛) ↔ 활성(채움 + 황토). 색만이 아니라 채움/테두리로도
구분(접근성). 비로그인 시 공감·댓글은 로그인 유도로 연결.

## 접근성
- 본문 대비 AA 이상(`#20211c` on `#faf8f3`).
- 모든 폼 입력에 `label`. 링크/버튼 키보드 포커스 가시.
- 색에만 의존하지 않음(카테고리는 텍스트 라벨).
