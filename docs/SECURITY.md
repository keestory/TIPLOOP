# 보안 정책

## API 키 관리
- API 키는 환경 변수로만 관리
- `.env` 파일은 `.gitignore`에 포함
- 코드에 하드코딩된 키 금지 (린터로 강제)

## 에이전트 권한
- 에이전트는 최소 권한 원칙을 따름
- 파일 시스템: 프로젝트 디렉토리 내에서만 작동
- 네트워크: 허용된 엔드포인트만 접근
- 외부 서비스: 명시적 허용 목록 관리

## 코드 실행
- 에이전트가 생성한 코드는 샌드박스에서 실행
- 시스템 명령어 실행은 허용 목록 기반
- 위험한 명령어 (rm -rf, git push --force 등) 차단

## 연구 노트와 첨부 공유

- 연구 노트와 두 Storage 버킷은 기본 비공개이며 `anon`·`authenticated`에 앱 테이블 직접 권한을 주지 않는다.
- 작성자가 명시적으로 만든 링크만 7일 동안 유효하다. 원문 링크 토큰과 첨부별 미디어 grant는 SHA-256 해시만 DB에 저장한다.
- 공유 데이터는 링크 생성 시점의 스냅샷이다. 이후 원본 수정이나 새 첨부를 기존 링크에 자동 노출하지 않는다.
- 미디어는 공개 버킷이나 signed URL이 아니라 `shared-media` Edge Function이 매 요청 활성·만료·회수 상태, 첨부 인덱스, 소유자 경로, MIME·확장자를 확인한 뒤 스트리밍한다.
- 미디어 grant는 원문 공유 토큰에서 단방향으로 파생한 첨부별 토큰이라 인프라 요청 로그만으로 원문 링크를 복원할 수 없다.
- 공유 생성·중지 POST는 same-origin 요청만 허용한다. 공개 응답은 `no-store`, `noindex`, `no-referrer`, `nosniff`, frame 차단을 적용한다.
- 이미 내려받거나 캡처한 파일은 공유 중지 뒤 회수할 수 없음을 생성 전에 알린다.
