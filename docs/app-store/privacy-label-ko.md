# TIPLOOP App Privacy 입력안

App Store Connect 입력 전 운영 로그와 실제 SDK 수집을 다시 확인한다.

| 데이터 유형 | 사용자 연결 | 추적 | 목적 |
|---|---:|---:|---|
| 이름 | 예 | 아니요 | 앱 기능 |
| 이메일 주소 | 예 | 아니요 | 앱 기능 |
| 사용자 ID | 예 | 아니요 | 앱 기능 |
| 사진 또는 비디오 | 예 | 아니요 | 앱 기능 |
| 기타 사용자 콘텐츠(노트·프로필 선택값) | 예 | 아니요 | 앱 기능 |
| 제품 상호작용(작성 방식·온보딩 상태) | 예 | 아니요 | 앱 기능 |
| 기타 데이터(직군·연차·업종·관심 주제) | 예 | 아니요 | 앱 기능 |

- 광고 추적 또는 제3자 광고를 사용하지 않는다.
- 사용자가 만든 노트·첨부·공유 링크는 계정 삭제 시 제거한다.
- 진단·대략적 위치 등은 Vercel·Supabase의 실제 운영 로그 설정을 확인한 뒤 최종 선택한다.
