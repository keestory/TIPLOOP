# 스킬: 문서 관리 (Doc Gardening)

> 문서의 최신성, 정확성, 구조를 주기적으로 관리하는 워크플로

## 트리거
- 주기적 스케줄 (매일)
- 수동 실행
- 대규모 코드 변경 후

## 워크플로

### 1단계: 스캔 (DocGardener)
- docs/ 전체 파일 스캔
- 오래된 문서 감지 (30일+ 미수정)
- 깨진 링크 감지
- 문서 커버리지 확인

### 2단계: 코드-문서 일관성 검증 (DocGardener)
- AGENTS.md와 실제 디렉토리 구조 비교
- ARCHITECTURE.md와 실제 레이어 구조 비교
- 품질 등급과 실제 상태 비교

### 3단계: 수정 PR 생성 (DocGardener)
- 오래된 내용 업데이트
- 깨진 링크 수정
- 부재 문서 초안 생성

### 4단계: 자동 병합
- 경미한 수정: 자동 병합
- 주요 변경: 사람 리뷰 후 병합

## 검사 항목 체크리스트
- [ ] 모든 링크 유효
- [ ] AGENTS.md ≤ 200줄
- [ ] 필수 파일 모두 존재
- [ ] 문서 내용이 현재 코드 반영
- [ ] 인덱스 파일 업데이트
